# game

Консольный пошаговый автобаттлер. Игрок создаёт и прокачивает персонажа, а бои
проходят автоматически. Цель — одержать 5 побед подряд.

## Требования

- Go 1.26 или новее

## Запуск

```sh
git clone https://github.com/yhgrwav/game/edit/main/
cd game
go run main.go
```

## Как играть

1. Выбираешь класс персонажа: воин, варвар или разбойник. Атрибуты (сила,
   ловкость, выносливость) выдаются случайно.
2. Персонаж автоматически сражается со случайным монстром — удары идут по очереди,
   пока у кого-то не кончится здоровье.
3. После победы здоровье восстанавливается, можно повысить уровень (в том числе
   классом, отличным от стартового) и заменить оружие на выпавшее из монстра.
4. Поражение — создаёшь нового персонажа.
5. 5 побед подряд — игра пройдена.

Максимальный суммарный уровень персонажа — 3.

## Структура

- `internal/entity` — описания сущностей (герой, монстр, боец, оружие, бонусы)
- `internal/catalog` — игровые таблицы (классы, оружие, бонусы, монстры)
- `internal/methods` — операции над сущностями (создание, прокачка, расчёт боя)
- `internal/events` — игровые сценарии (создание персонажа, бой, действия после боя)
- `main.go` — игровой цикл
